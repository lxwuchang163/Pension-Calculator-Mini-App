## 1. Product Overview
养老金测算H5应用，帮助用户快速计算未来养老金领取金额，支持全国各省市社保政策参数。
- 面向所有关注养老规划的用户，提供简单易用的测算工具
- 市场价值：普及养老规划意识，帮助用户合理规划退休生活

## 2. Core Features

### 2.1 User Roles (if applicable)
无需角色区分，所有用户可直接使用

### 2.2 Feature Module
1. **首页/测算页**：核心测算表单，实时计算展示结果
2. **结果展示**：详细的养老金构成分析和图表展示

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 测算页 | 地区选择 | 下拉选择全国各省市/直辖市 |
| 测算页 | 个人信息表单 | 年龄、性别、缴费基数、缴费年限、个人账户余额输入 |
| 测算页 | 测算按钮 | 点击触发计算，展示详细结果 |
| 测算页 | 结果展示 | 基础养老金、个人账户养老金、总养老金 |
| 测算页 | 图表展示 | 可视化展示养老金构成 |

## 3. Core Process
用户进入应用 → 选择所在地区 → 输入个人信息 → 点击测算 → 查看测算结果和分析

```mermaid
flowchart LR

  B --> C["输入个人信息"]
  C --> D["点击测算按钮"]
  D --> E["展示测算结果"]
  E --> F["查看详细分析"]
```

## 4. User Interface Design
### 4.1 Design Style
- **主色调**：温暖的橙色渐变 (#FF6B35 → #F7931E)，代表活力与希望
- **辅助色**：深蓝色 (#1D3557) 用于文本和图表，白色背景
- **按钮风格**：圆角矩形，渐变填充，带有柔和阴影
- **字体**：使用现代无衬线字体，大号标题配合清晰层级
- **布局风格**：卡片式布局，各模块清晰分隔，底部悬浮测算按钮
- **图标风格**：简洁的线性图标，使用 Lucide 图标库

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 测算页 | 顶部区域 | 品牌标题 "养老金测算" + 副标题 "规划美好退休生活" |
| 测算页 | 地区选择 | 下拉选择器，带有省/市二级联动 |
| 测算页 | 表单区域 | 分组卡片布局，输入框带标签和提示 |
| 测算页 | 测算按钮 | 底部悬浮，橙色渐变，大字号 |
| 测算页 | 结果展示 | 卡片式展示，突出养老金金额，包含饼图 |
| 测算页 | 动画效果 | 结果卡片淡入，数字滚动动画 |

### 4.3 Responsiveness
- **移动端优先**：主要针对手机端优化，完美适配 320px-480px 宽度
- **响应式适配**：支持平板和桌面端展示
- **触摸优化**：大点击区域，流畅的触摸反馈

### 4.4 3D Scene Guidance (if applicable)
不涉及3D场景
